Mock-up · project colours, badges and shapes · not built yet

Every bubble says which project it belongs to.

Each project gets a colour and a short code. The code sits in a small badge on top of the bubble, and the colour tints its fill. Activity types can change the bubble's shape. The status rings still mean the same thing on every shape.

1 · Project colour

Every new project picks the next colour from a set of six. Amber and teal are kept for status, so they are never used for projects. Inbox stays neutral.

violet sky rose lime indigo clay
make Goforex violetcolour Propr rose

2 · Badge

A two- or three-letter code, made from the project name (Goforex → GO, Zupaflow → ZF), sits on the top edge of each bubble in the project's colour. Inbox items get no badge.

call Goforex GFX

3 · Shape by activity

Items are circles by default. You can give a type of work its own shape, and it applies to items tagged with that type. Shapes keep the same area, so priority still reads from size.

show calls as squaresshow reviews as diamondsresearch is a hexagon

Unchanged: amber ring means it needs you, teal ring means an agent is on it, size is priority, and the ring position is time. Agents can set tags; you set colours and shapes by typing.
